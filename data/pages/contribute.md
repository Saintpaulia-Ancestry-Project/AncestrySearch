# Contribute cultivars

Hybridizers and collectors can add cultivars to this database: a name, the seed and pollen parents, a description, registration details and photos. You can add as many cultivars as you like in one submission. Corrections to cultivars already in the database are welcome too.

## How it works

- Fill in the form below. Only the cultivar name is required. A cultivar may have a description with no parentage, or parentage with no description.
- Your work is saved in your browser while you type, so you can close the page and come back on the same device.
- When you are done, check the list and press **Send my submission**. If sending fails, use **Download a copy (.csv)** and email the file to the project.
- A reviewer checks every cultivar before anything is added to the database. Nothing you send appears on the site automatically, and review can take a while.
- Your contact details are never published. Your name is shown as the credit.

## Before you start

- **About you:** your name is the public credit. Your contact (email) is private and is used only if the reviewer has a question. It is never published.
- **License:** the data and photos you contribute are published under CC BY 4.0, like the rest of the database. You keep your copyright; others may reuse the data with credit. You must tick the agreement to send.
- Have your photos ready as image files (JPEG, PNG or WebP). The form shrinks each one to 1600 pixels on the longest side and saves it as a JPEG. This removes camera data such as the location. The photo is resized on your device before it is sent.

## Filling in a cultivar

- **Name:** the cultivar name as registered or commonly written. If the name is already in the database you are told, and you can choose between a different cultivar with the same name, or adding your details to the existing one.
- **Type:** cultivar (the default), seedling (not named) or species.
- **Hybridizer:** write names as Surname, Given (for example Dates, Jimmy). Several hybridizers can be given. Start typing to pick an existing person.
- **Parentage:** start typing a parent's name and pick it from the suggestions. If a name is used by several cultivars, the list shows the hybridizer so you can choose the right one. A name that is not in the database is still accepted and added as a parent-only name. For a sport, fill in only **Sport of**. For a complicated cross (for example a named seedling or several generations), use the parentage note.
- **How sure are you?** Mark the parentage as known, assumed or unsure. Uncertain parentage is shown as such on the site.
- **Registration:** the AVSA registration number and date, if registered.
- **Description:** size class, color, bloom, foliage and anything else worth knowing. Describe what you observed yourself; do not copy from catalogs.
- **Photos:** each photo needs a credit (the photographer) and your confirmation that you may share it. Add a caption if useful.

## Several cultivars at once

Use **Add another cultivar** for each one. **Duplicate this entry** copies the hybridizer and parents, which saves time for a series from one cross. Two cultivars in the same submission may name each other as parents.

## After you send

You see a confirmation with a reference number (keep it if you want to ask about the submission). Sending the same submission again before it is reviewed updates it rather than adding duplicates. If you have questions or want something removed, contact the project and quote the reference.

## Tips

- Spell parent names the way they are registered; the checker looks for near matches but cannot guess.
- A single clear photo of the bloom and one of the whole plant are plenty.
- Submit what you know. Missing details can be added later as a correction.
